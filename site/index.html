Why use this InPage to PDF converter?

Millions of Urdu newspapers, books, exam papers and school documents are typed in InPage — but opening an .inp file needs the InPage software, which only runs on Windows. This free online tool converts InPage to PDF directly in your browser, so anyone can read, print and share Urdu documents on any device.

  • Original Nastaliq calligraphy — Jameel Noori Nastaleeq, the same font family InPage documents use
  • Bold text preserved — headings and bold words look bold in the PDF
  • Exact spacing — line breaks, vertical gaps and the wide spaces between MCQ options stay as typed
  • Tables rebuilt — bordered RTL tables with the header row repeated
  • Urdu numbers fixed — dates, marks and question numbers in correct order
  • No software needed — works on mobile, Windows, Mac and Linux; no InPage, no font installation
  • Private — files are deleted automatically after 24 hours

How to convert an .inp file to PDF

  1. Drag your .inp file into the box above (or click to choose files — several at once is fine).
  2. Press Convert to PDF. Conversion takes a few seconds per file.
  3. Preview the PDF right in the page, then download it. Done!

Frequently asked questions

What is an .inp file?

.inp is the document format of InPage, the Urdu desktop-publishing software widely used in Pakistan for newspapers, books, question papers and school/administrative documents.

Do I need InPage software to convert .inp to PDF?

No. This converter reads the .inp file format directly — InPage or Windows is not required. It works in any modern browser, including mobile.

Will the Urdu formatting stay the same?

Yes. The original Jameel Noori Nastaliq calligraphy, bold text, font sizes, line breaks, vertical gaps, MCQ option spacing and tables are preserved from the original file.

Is it free? Are my files safe?

Completely free. Uploaded files are processed automatically and permanently deleted from the server after 24 hours. Nothing is shared with third parties.

Can I convert many files at once?

Yes — select or drop multiple .inp files (up to 30 per batch) and each one produces its own PDF.
